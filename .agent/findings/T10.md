## What was done
- `deploy/common/gaming-pc-wakeup.env.example`: all seven `WOL_*` variables, `KEY=value`, defaults filled, placeholders for `WOL_MAC`/`WOL_HOST`, comments on where each host keeps the file.
- `deploy/pi/install.sh`: `set -eu`, cd to repo root, `UV_PYTHON_DOWNLOADS=never`, `uv venv --python python3` if `.venv` is absent, `uv export --frozen --no-dev --no-hashes` to a temp file, `uv pip install --index https://www.piwheels.org/simple --index-strategy unsafe-best-match -r <file>`. The only place the project mentions piwheels.
- `deploy/pi/gaming-pc-wakeup.service`: `After/Wants=network-online.target`, `User=pi`, `WorkingDirectory=/home/pi/gaming-pc-wakeup`, `EnvironmentFile=/etc/gaming-pc-wakeup.env`, `ExecStart=.../.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000`, `Restart=on-failure`, `RestartSec=5`, `WantedBy=multi-user.target`.
- `deploy/termux/install.sh`: Termux shebang, `pkg install -y python uv rust`, `UV_PYTHON_DOWNLOADS=never uv sync --no-dev`.
- `deploy/termux/boot.sh`: Termux shebang, `termux-wake-lock`, cd `$HOME/gaming-pc-wakeup`, `set -a; . $HOME/gaming-pc-wakeup.env; set +a`, `exec .venv/bin/uvicorn ...` with output appended to `$HOME/gaming-pc-wakeup.log`.
