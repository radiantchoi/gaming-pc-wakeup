- Performed by: orchestrator (Claude Fable 5.1) directly, at the user's request
- Completed: 2026-09-17

## What was done
- `app/config.py`: `ssh_user`, `ssh_key`, `ssh_port` (22), `ssh_timeout` (10.0) from `WOL_SSH_*`; `sleep_configured` property; `ValueError` naming the missing variable when only one of user/key is set, and naming `WOL_SSH_KEY` when the file does not exist.
- `app/sleep.py`: `build_ssh_argv` and `request_sleep`; `subprocess.run(..., capture_output=True, text=True, timeout=..., check=False)`; non-zero exit → `RuntimeError(stderr or "ssh exited with N")`; missing `ssh` and timeout mapped to `RuntimeError`. Remote command is the constant `schtasks /run /tn gaming-pc-sleep`.
- `app/main.py`: `_check_token` shared by `/wake` and `/sleep`; `POST /sleep` → 503 unconfigured, 401 bad token, 502 on `RuntimeError`, 200 `{"status": "sleeping", "host"}`.
- Tests: `tests/test_sleep.py` (argv, kwargs, error mapping, endpoint codes and body, 405 on GET) and additions to `tests/test_config.py` (defaults, parsing, pair validation, missing key file, numeric errors). `subprocess.run` is monkeypatched; no real `ssh` in tests.
- `deploy/windows/sleep.ps1`: P/Invoke `SetSuspendState(false, false, false)` after a 2 s delay.
- `deploy/common/gaming-pc-wakeup.env.example`: four `WOL_SSH_*` lines.
- `deploy/termux/install.sh`: adds `openssh`.
- `README.md`: "Sleep over SSH (optional)" subsection (OpenSSH Server, scheduled task as SYSTEM with no trigger, key generation, restricted `authorized_keys` line, `icacls` fix, host-side test), endpoint table row, env table rows, curl example.
